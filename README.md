# Magnifique ❤️

Petit site romantique (HTML/CSS/JS pur, sans dépendance) : intro animée, question tapée à la machine,
polaroïds, fond animé, musique douce optionnelle, puis une animation différente selon la réponse
(feux d'artifice + confettis pour « oui », nuit étoilée + lanternes pour « prenons le temps »).

## Personnaliser
- **Photos** : voir `images/LISEZMOI.txt` (photo1.jpg, photo2.jpg…).
- **WhatsApp, légendes, musique** : bloc `CONFIG` tout en haut de `script.js`.
- **Textes** : directement dans `index.html`.

## Mettre en ligne (gratuit)
GitHub → Settings → Pages → *Deploy from a branch* → branche + dossier `/ (root)`. Envoie ensuite le lien à Magnifique.
